Implementations & demo

This host runs a live DKIM2 demonstration server. Four independent implementations — in Python, Perl, Go, and C — interoperate in the project repository. Two mailing-list managers on this host sign with DKIM2 as they forward:

  • Mailman (this host)
  • Sympa (this host)

Subscribe to any of these lists to receive DKIM2-signed list mail and see how each kind of list change is recorded:

  • test@mailman.dkim2.com — subject prefix and footer
  • test-subject-only@mailman.dkim2.com — subject prefix only
  • test-body-only@mailman.dkim2.com — footer only
  • test-passthrough@mailman.dkim2.com — no changes
  • dkim2stock@mailman.dkim2.com — unpatched Mailman behaviour, signed by the Postfix milter route (guide)
  • test@sympa.dkim2.com — Sympa

Other DKIM2 implementations

DKIM2 is being built independently in several places. These are the efforts we know of beyond this host:

ImplementationByLanguageWhat it does
croessner/dkim2 Christian Rößner Go A dkim2d daemon, a milter, and an Exim local_scan; signs and verifies. Apache-2.0
go.turscar.ie/dkim2 Steve Atkins Go A library, plus dkim2sign, dkim2verify and dkim2explain command-line tools. BSD-2-Clause
turscar/dkim2tests Steve Atkins — Conformance test vectors — the set every verifier in this project is run against. BSD-2-Clause
mail-auth Stalwart Labs Rust A library: Ed25519 and RSA signing with chain verification, and several selectors in one signature. Also in the Stalwart mail server; try it in the browser at mail-auth.stalw.art. Apache-2.0 or MIT
SocketLabs DKIM2 verify SocketLabs (Brian Godiksen, now Infobip) hosted A verifier, in the browser and over a JSON API. Also reachable as dkim2.net
dkim2.eu Steve Atkins hosted A validator and explainer, with its own list of implementations
dkim2.pub Christian Rößner (mail.de) hosted A validator and SMTP reflectors
halon-extras-dkim2 Halon — An open-source module for the Halon MTA; experimental DKIM2 signing and verification
Momentum MTA Bird — A commercial MTA; experimental DKIM2 signing and verification in v5.3

As observed in November 2026. Working on a DKIM2 implementation that belongs here, or spotted something wrong about yours? Please let us know.
